### 1. [Sagan project](https://github.com/RameshMF/sagan)
- This is the spring.io website which has been open source since 2014 or thereabouts and is developed by the Spring team. Used as an example for how they would build a real life project. Sadly doesn't have JWT auth. 

### 2. [Klaw](https://github.com/Aiven-Open/klaw)
- Klaw is a web application which automates the process of creating and browsing Apache Kafka topics, acls, avro schemas, connectors by introducing roles/authorizations to users of various teams of an organization. It is fully open-source
